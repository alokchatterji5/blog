The short version

OpenCode is an open-source coding agent for the terminal. It installs in a minute, works with Gemini, OpenAI, Anthropic, free Groq models or local Ollama, shows diffs before editing, and asks before touching the file system. I'm using it as my daily driver.

AI assistants in the terminal are the new frontier, but many come with vendor lock-in: a specific set of models and a proprietary ecosystem. I wanted an agent that is open-source and model-agnostic, where I can use my favourite provider or my own local LLMs. That is what I found in OpenCode.

Docsopencode.ai/docs

Setup

It took a few minutes from install to a working agent.

One command downloads and runs the install script. It completed without any hitches for me.

curl -fsSL https://opencode.ai/install | bash

This opens a browser window to log in or create an account.

opencode auth login

Go to your project directory, run opencode, then use /init inside the session. It scans the project, builds a context map and prepares the agent to work with awareness of the codebase.

/init

Model freedom

This is where it sets itself apart. Being open source gives it a transparency that proprietary tools can't match, and it's provider-agnostic:

  • Cloud models: Gemini, OpenAI or Anthropic, using my existing API keys.
  • Local LLMs: I've been experimenting with Ollama and OpenCode connects to my local models seamlessly. Good for privacy, offline work and cost.
  • Fast free models: out of the box it is configured to use free Groq models, which are quick and responsive.
  • Any provider: I can switch models and providers as my needs change.

The Zen agent framework

It's more than a chat wrapper. The Zen agent framework gives it tool use (reading and writing files, running commands), planning (I can see a step-by-step plan before it changes anything on complex tasks), and safety (it asks permission before modifying the file system).

Features I use daily

  • Diff-first edits. Seeing the diff before it's applied is a big confidence boost.
  • TUI. The interactive terminal UI makes it easy to manage the conversation and review work.
  • Session persistence. Close the terminal, come back later, the session is still there.
  • LSP awareness. It uses my LSP for context-aware suggestions.

The GitHub integration lets me review pull requests and get detailed analysis from the terminal, like a dedicated AI reviewer on the team.
