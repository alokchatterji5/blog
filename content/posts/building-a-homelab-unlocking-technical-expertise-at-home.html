The short version

I wanted a playground to deepen my technical knowledge. It grew from a small experiment into virtualization, VLANs and NAS storage that mimic a real IT environment, and I have kept it modular so it can keep growing.

What it is for

GoalWhat I do with it
SkillsVirtualization, networking, containerization

StorageLearn efficient data storage and management
NetworkingVLAN configurations and secure network setups
Professional growthUnderstand enterprise-grade tech in a personal sandbox

What is in it

It is meant to mimic a real IT environment: virtual machines on a single host (VMware or Proxmox), VLANs to separate traffic the way an enterprise would, and a NAS for scalable, reliable storage, plus a dedicated space to try new software and workflows. The design is modular, so I could start small and expand.

What it has given me
  • Practical skills in system administration, networking and storage.
  • Confidence implementing things like VLANs and virtual machines.
  • A base for longer-term projects.

Getting started

Decide what you want: virtualization, networking or cloud technologies.

Set up your first server or virtual machine on whatever you have lying around.

Start with free, open-source software such as Proxmox or VirtualBox.

Build in phases. Basic setups first, complexity later.

Write down your experiments and learn from the failures.

A homelab is an investment in your own growth. Start small, build it up, and see what it does to your understanding.
