A Crew of AI Agents Runs My Homelab.

This is how I run it with agents:

🕶️ EDITH takes my messages and hands out the work
📊 FRIDAY watches health, stats and backups
🎬 VERONICA runs the media stack
🛡️ JARVIS manages users and access
🦾 DUM-E builds and deploys

They all run on ZeroClaw, a small self-hosted agent gateway. I never gave them a shell, only a short list of commands I wrote, and anything risky waits for my tap on Approve.
